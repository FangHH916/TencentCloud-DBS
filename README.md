# 安心转账：适老语音支付 Demo

独立的 DBS DCTA 赛题原型。通过大字界面、语音朗读、逐步澄清和明确授权，练习给已登记家人转账。使用模拟资金、规则解析与模拟身份认证；未接入真实银行或大模型。

## 启动

需要 **Node.js 24 或更新版本**。运行应用无需安装 npm 依赖或提供密钥：

```powershell
node server.mjs
```

Windows 也可双击 start-demo.cmd。打开 http://127.0.0.1:8787 ，服务仅监听本机地址。PORT 环境变量可更改端口。

草稿、模拟余额、交易和审计记录默认保存到 data/demo.sqlite。浏览器保留会话 Cookie 时，刷新或服务重启可恢复同一练习；清除 Cookie、使用另一浏览器或超过 Cookie 有效期，会建立新练习。重新练习需二次确认，会替换当前保存的会话。

如需独立数据库，可设置 DCTA_DB_PATH；设置为 :memory: 可使用临时数据。每个实例使用独立数据库文件。数据库、日志和 output/ 截图均被 Git 忽略。

## 适老流程

1. 点击“试一试：给小明转账”，发送“给小明转三百块”。
2. 一次确认一个缺失信息：币种、付款账户。只在当前问题询问币种时，“是的”可确认 SGD；“好的”永远不会执行付款。
3. 点击“修改这笔”修改金额、收款人或付款账户，其他信息保留。单笔也支持“金额改成五百”“改用往来账户”“收款人改成妈妈”。
4. 点击“再听一遍付款详情”，核对姓名、收款账户尾号、金额、币种和付款账户。
5. 点击“下一步：核对并授权”，勾选核对框，再确认模拟付款。付款前可以取消草稿；完成后不能通过取消草稿撤销。
6. 字号、自动朗读与朗读速度会保存在当前浏览器。手机提交后自动定位当前问题或核对按钮，支持 320px 及以上宽度。

语音识别使用浏览器引擎，可能需要联网和麦克风权限；识别结果先显示为文字，用户检查后发送。朗读依赖设备中文语音。浏览器不支持语音时，可使用完整文字流程。尚未进行真实老年用户测试，不宣称方言准确率或已提升操作成功率。

## 异常恢复

付款请求发出前，浏览器保存待确认的草稿编号；请求失败后查询同一笔交易的状态，不自动再次执行。若已完成，显示已保存的余额和付款回执。若结果仍待确认，则暂停新付款，允许继续查询，或停止这笔待确认付款后再操作。

服务在会话副本上执行变更，SQLite 提交成功后才发布新状态。余额、交易、草稿状态和日志在同一数据库事务中保存；写入失败不会发布未保存的扣款。保存采用版本比较，防止旧副本覆盖新数据。重复提交同一授权只能成功一次。

模拟认证私钥和待用授权不落盘。重启后保留已完成交易，但未执行的旧签名失效，必须重新核对授权。此策略适用于本地原型，不等同于真实银行的持久认证系统。

## 更多演示

- 同名：“给 John 转500”，逐步选择 John Tan / John Lim、币种和账户。
- 多笔：“从储蓄账户给妈妈转200新元，再给Alice转150新元”。每次最多三笔，整批预检和提交。多笔修改通过对应卡片操作，避免错改其他交易。
- 高额：“从储蓄账户给妈妈转2500新元”，触发风控拦截。
- 安全实验室：未授权执行、授权后篡改、重复提交、提示注入、日志篡改。测试账户隔离，不改变当前练习余额。
- 审计记录：查看原始指令、澄清、修改、授权、执行和恢复事件，导出 JSON。

初始余额：储蓄 SGD 12,500，往来 SGD 3,200。单笔上限 SGD 2,000，一分钟最多五笔。已登记收款人为妈妈、孙子陈小明、John Tan、John Lim、Alice。

## 架构与边界

网页 → 规则解析 → 结构化草稿 → 独立只读语义校验与确定性风控 → 固定核对界面 → 模拟认证器 Ed25519 签名 → 交易网关 → SQLite 模拟账本。

签名绑定会话、草稿摘要、版本、nonce 和有效期。修改明确字段会留下独立记录并更新摘要，使旧授权失效。网关执行前再次核对内容、签名、草稿状态、余额和交易频率。

离线解析仅覆盖明确金额的 SGD 转账、有限中英文名称和指定修改句式。模糊金额、条件交易、其他币种、复杂语言会要求改写或拒绝。lib/model-adapter.mjs 仍是未启用的真实模型接口契约。

身份与认证均为模拟，模块处于同一 Node 进程。哈希链和检查点保存在同一数据库，只能在检查点可信的假设下发现变化，无法抵御服务器管理员重写整库。真实模型、独立验证模型、真实 KYC、WebAuthn、生物认证、银行 API 和外部可信存证尚未实现。

## 测试

```powershell
npm.cmd test

# 浏览器测试需要开发依赖
npm.cmd ci
npm.cmd run test:browser
```

Windows 浏览器测试优先使用已安装的 Edge。其他环境先执行 npx playwright install chromium。浏览器脚本自动启动独立测试服务，不占用演示数据库。

- 33 项 Node 测试覆盖金额解析、澄清、修改、授权失效、篡改、重复提交、批次、风险、SQLite 重启恢复、保存失败回滚、版本冲突和会话隔离。
- 浏览器测试覆盖逐步转账、修改弹窗、偏好记忆、响应丢失后的查询、待确认付款停止、手机布局、安全实验室、日志和不可信输入。
- 语音事件在自动测试中模拟；真实麦克风识别、设备朗读效果和目标用户可用性需要人工验证。
